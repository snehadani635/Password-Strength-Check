# 🔐 Password Strength Checker

A simple and responsive Password Strength Checker built using HTML, CSS, and JavaScript. This project checks the strength of a password in real time and classifies it as Weak, Medium, or Strong based on its length.

## 🚀 Features

- Real-time password strength detection
- Weak, Medium, and Strong indicators
- Dynamic border color changes
- Responsive design
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How It Works

- Password length less than 4 characters → Weak
- Password length between 4 and 7 characters → Medium
- Password length 8 characters or more → Strong

The strength message and input border color update automatically as the user types.

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a password to see the strength indicator in action.
