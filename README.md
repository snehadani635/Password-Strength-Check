# 🔐 Password Strength Checker

A simple and interactive Password Strength Checker built using **HTML**, **CSS**, and **JavaScript**. This project evaluates password strength in real-time and provides visual feedback to users.

## 🚀 Features

- Real-time password strength detection
- Checks for:
  - Minimum password length (8+ characters)
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@#$%^&* etc.)
- Visual strength indicator bar
- Strength levels:
  - Weak
  - Medium
  - Strong
- Clean and responsive user interface
